# PRYSMERK

Портфоліо-проєкт: багатосторінковий імерсивний сайт-каталог одягу вигаданого бренду PRYSMERK.

Бренд, товари й тексти вигадані. Це демонстраційний проєкт. Покупка неможлива, форма замовлення нічого нікуди не надсилає.

## Стек

Чисті HTML, CSS і JavaScript. Без фреймворків і готових шаблонів.

## Запуск локально

Сайт читає `data/products.json`, тому відкриття `index.html` подвійним кліком не спрацює. Потрібен локальний сервер:

```
python3 serve.py
```

Потім відкрийте http://localhost:8000 (зупинити: `Ctrl+C`).

`serve.py` швидший і надійніший за `python3 -m http.server`: той має чергу з'єднань усього на 5, і при відкритті сторінки (~25 файлів одночасно) частина запитів іноді обривається. `python3 -m http.server 8000` теж працює, але може інколи губити файли.

## Шрифти

Unbounded (заголовки) і Onest (текст) із Google Fonts. Файли лежать у `fonts/`, тому сторінка не чекає зовнішній сервер. Знак гривні ₴ лежить у підмножині `cyrillic-ext`, тому вона підключена теж.

## Мови

Інтерфейс українською й англійською. Українська: ціни в гривнях. Англійська: у доларах.
