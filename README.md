# PRYSMERK

Портфоліо-проєкт: багатосторінковий імерсивний сайт-каталог одягу вигаданого бренду PRYSMERK.

Бренд, товари й тексти вигадані. Це демонстраційний проєкт. Покупка неможлива, форма замовлення нічого нікуди не надсилає.

## Стек

Чисті HTML, CSS і JavaScript. Без фреймворків і готових шаблонів.

## Запуск локально

Сайт читає `data/products.json`, тому відкриття `index.html` подвійним кліком не спрацює. Потрібен локальний сервер:

```
python3 serve.py
```

Потім відкрийте http://localhost:8000 (зупинити: `Ctrl+C`).

`serve.py` швидший і надійніший за `python3 -m http.server`: той має чергу з'єднань усього на 5, і при відкритті сторінки (~25 файлів одночасно) частина запитів іноді обривається. `python3 -m http.server 8000` теж працює, але може інколи губити файли.

## Шрифти

Unbounded (заголовки) і Onest (текст) із Google Fonts. Файли лежать у `fonts/`, тому сторінка не чекає зовнішній сервер. Знак гривні ₴ лежить у підмножині `cyrillic-ext`, тому вона підключена теж.

## Структура

```
index.html            головна
section.html          розділ (?s=men | women | kids): підрозділи, ряди плашок, фільтри
product.html         товар (?id=...): фото, опис, вікно замовлення
about / privacy / delivery / returns / contacts .html   інформаційні сторінки
css/                  colors.css (усі кольори), fonts.css, base.css, glow.css, home/section/product/info.css
js/                   translations.js (усі тексти), i18n, layout (меню, футер), data (товари, ціни),
                      catalog, product, order (форма), hero (анімація відкриття), glow-engine + glow (свічення),
                      modal, transitions
data/products.json    товари (ціни в гривнях і доларах задані вручну, курс не рахується)
fonts/                Unbounded і Onest (файли Google Fonts)
serve.py              локальний сервер
```

## Безпека

- У репозиторії немає ключів і паролів, `.gitignore` захищає `.env`, `*.key`, `*.pem` та подібне.
- Дані з форми й полів фільтра ніколи не вставляються в сторінку як розмітка (немає `innerHTML`): тільки `textContent`.
- Форма замовлення візуальна: нічого не надсилає і не зберігає. Полів для номера картки немає.

## Свічення фону

Чотири великі м'які шари (дымка, діагональний розмах, ядро, темний кут), складені з `radial-gradient`, без `blur`. Шари повільно пливуть (лише `transform`), зверху шум 4% проти сходинок на темних градієнтах. Усе керується змінними на початку `css/glow.css` (там же пояснення простими словами):

- `--g-k` загальна сила (зараз 1.4), `--a-haze/sweep/core/dark` піки прозорості шарів;
- `--gx --gy` де ядро (відсотки екрана), `--ga` кут розмаху; композиції для головної, розділів, товару й інформаційних сторінок.

Піки шарів підібрані так, щоб найсвітліша точка не перевищувала ~56 з 255: вище цього приглушений текст втрачає контраст 4,5 : 1.

## Мови

Інтерфейс українською й англійською. Українська: ціни в гривнях. Англійська: у доларах.
